Smart Home Inventory Tracker

Problem: ~30% of household food is wasted from untracked expiration dates. What if a barcode scan could solve it?

Barcode-driven inventory 75% xUnit test coverage Hangfire job scheduling
The Problem

The average household wastes ~30% of food. Root cause: expiration dates are invisible until it's too late. Manual tracking doesn't work because nobody does it.

My Approach

Barcode scanning as primary input — zero manual entry. Automated background jobs for expiration checks. Alert system surfaces items before they expire, not after.

Technical Depth
  • C# .NET Core backend with Entity Framework Core — code-first PostgreSQL schema design
  • Hangfire for recurring background jobs — expiration alerts at configurable intervals
  • Barcode lookup API integration for automatic product metadata on scan
  • 75% xUnit test coverage with integration tests for the full alert pipeline
  • Clean architecture: domain / application / infrastructure separation
