# Portfolio Site

A single-page freelance developer portfolio built with vanilla HTML, CSS, and JavaScript.

## Structure

- `index.html` — all markup and sections
- `styles.css` — all styles (CSS custom properties, responsive)
- `script.js` — nav, animations, filtering, form validation

## Sections

1. **Hero** — intro, CTA buttons
2. **About** — bio, stats
3. **Skills** — category cards, proficiency bars
4. **Projects** — filterable 6-card grid
5. **Contact** — validated form with mock submit

## Development

Open `index.html` directly in a browser — no build step required.
